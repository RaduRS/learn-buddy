# Fredoka

`Fredoka.ttf` is the variable Fredoka font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/fredoka), downloaded on 10 November 2026. It supports weights 300 to 700.

The font is bundled locally so the production build does not depend on a Google Fonts network response. Its SIL Open Font License is included in `OFL-Fredoka.txt`.
